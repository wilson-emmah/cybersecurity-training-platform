# Final-Year Project Scope

## General Objective
Design and develop an interactive cybersecurity awareness and attack-simulation training platform.

## Specific Objectives
1. Develop an interactive web-based cybersecurity training platform.
2. Simulate common cyber threats in a controlled environment.
3. Provide immediate feedback after user decisions.
4. Implement gamification using points, badges, levels and leaderboards.
5. Track user performance and training progress.
6. Provide administrators with scenario management and analytics.
7. Evaluate the platform through sample user testing.

## Modules
- Authentication
- Training
- Scenario engine
- Gamification
- Leaderboard
- Progress tracking
- Notifications
- Administration
- Reports
